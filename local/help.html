Local Only · Help & backups

Use this website — nothing to install

Open this dedicated Local Only website in Chrome, Edge or Safari. Create an apartment and import completed Stanford VFTCam 360° JPEGs. All work stays in this browser/profile on this device; it does not automatically appear on another computer. Bookmark this exact address.

Wait for Application ready offline before disconnecting. You can then reopen the same address offline when your browser retains the application cache. Installation is optional. If caching is unavailable, online editing still saves locally, but offline reopening will not work.

Safari/iPad may evict IndexedDB and offline caches after inactivity or under storage pressure. Private browsing, clearing website data or browser/device loss can remove projects. Do not rely on browser storage as your only copy. Export encrypted backups after each session; keep the password separately. Opening a backup in a different browser creates a separate local copy.

Photos and projects are NOT encrypted in IndexedDB. Clearing browser data, uninstalling, eviction or device loss can remove them. Keep encrypted backups on separate approved storage and protect your device. Browser storage is not a shared or permanent database.

Build and show an apartment

  1. Create an apartment. Upload completed 2:1 stitched JPEGs or ZIPs. Review, name and optionally group viewpoints.
  2. Connect Rooms: drag a destination onto its actual doorway. Enter the other room and position its return arrow. No position is guessed.
  3. Review Layout: generate the relationship diagram from saved doorways. Rearrange freely; tile adjacency never creates doorways.
  4. Preview & Finish: check every sphere and doorway, then Mark Ready to Show. Nothing is published. Later edits return it to Draft.

Save and recovery

Changes save automatically after a completed action. Wait for “Saved on this device”. Another window’s newer revision is protected; reopen after a conflict. Gallery → Manage apartment → Saved revisions restores a previous save as a new draft. History retains original photographs and consumes storage. Deletion removes only the chosen apartment after confirmation.

Encrypted backup and restore

Gallery → Export Backup. Choose a password of at least 12 characters and confirm it. The named, dated .shtour.zip uses the same AES-256-GCM format as Cloudflare. Passwords are never sent or logged. Keep the password separately; it cannot be recovered. Import Backup checks the whole file and always creates a NEW local draft. Older unencrypted .shtour packages work too. Duplicate imports require an explicit second-copy confirmation. Cancel leaves existing apartments untouched.

Export after each editing session and before deleting or clearing anything. Keep at least a current and previous encrypted backup on separate approved storage. Test a restore periodically. Staff accounts and guest invitations are not part of apartment backups.

Manual migration only

Export an encrypted backup, transfer it yourself, open the online Cloudflare Migration Center, select the intended apartment and confirm upload there. The local original remains unchanged. Local Only has no automatic synchronization or guest links.

Older local drafts

On the same origin/profile a detected legacy single-tour draft can be explicitly copied without modifying its original database. On a different address/profile use the older editor’s backup export, then Import Backup here. Never clear old browser data before checking the copy and an encrypted backup.

# Isolated official-button acceptance

This checklist requires explicit approval for the exact disposable Cloudflare Free and Paid accounts and approved GitHub template. It does not authorize any production changes. Use synthetic credentials, images, accounts and guest invitations. Publish the template for the rehearsal only after approval of its contents, license and third-party notices.

| Check | Evidence to record for each plan |
| --- | --- |
| Official button | Open the button from the approved public template. Confirm intended default revision and browser-only signup/authorization, install app access scope, destination GitHub organization, repository visibility and template copy. |
| Build and services | Confirm account, new Worker URL, D1, KV, SQLite Durable Object, assets, migrations and permissions. Confirm no subscription lookup, plan prompt from the application, payment change or unintended resource creation. Check the provider’s billed-usage dashboard without changing settings. |
| Bootstrap | Enter a synthetic password-manager-generated key in the Deploy form. Open the successful build’s website URL or Visit link. Verify first Administrator creation, sign-in, wrong and expired keys, concurrent submits and redeployment. Ensure the key never appears in source or logs and cannot claim another installation. Record the fresh wizard completion screen separately from a recovery build. |
| Application | Create scoped Staff, upload a synthetic JPEG, save and edit an apartment, publish and use a guest invitation. Verify denied scope and cross-agency access. |
| Backup and restore | Run the maintenance tool using a disposable account token. Collect verified digest and availability evidence. Restore into new unclaimed resources, interrupt and resume the same backup, then sign in and compare image bytes, permissions and guest behavior. Test a missing image, wrong key and corrupted archive. |
| Updates | Approve an additive upgrade against the agency’s own Git branch. Record before/after deployment IDs, retained credentials, data and bindings. Re-run and prove the migrations are idempotent. Roll back to a compatible retained version and verify sign-in. Test preview isolation and denied unreviewed promotion. |
| Closeout | Revoke the disposable token and invitations, retain protected sanitized receipts, and agree on cleanup separately. Record exact observed Cloudflare permissions and UI steps. |

Account-plan names describe test evidence. Installation does not require proof of plan. The owner deferred the Workers Paid rehearsal. It is outside the limited Workers Free pilot decision. See the [pilot checklist and evidence](PILOT.md).

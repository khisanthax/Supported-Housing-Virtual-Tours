I lost my key or setup expired

Ask the person who runs your Cloudflare account to help. The new code lasts 30 minutes.

  1. Click Make a setup code below. Copy the code and keep it private.
  2. In Cloudflare, open Workers & Pages. Choose this site. Open Settings → Variables and Secrets.
  3. Add LT360_SETUP_CODE. Set its type to Secret. Paste the code and deploy the change.
  4. Come back here. Use the new code in the setup key box.

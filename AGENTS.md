# Working on this project

At the start of each session, read README.md, deployment and feature guides, the latest LOGBOOK.md entries, and Git status. Identify unfinished work and plan the next implementation. Use a feature branch for substantial changes. Implement, run relevant tests, fix defects, update documentation and the logbook, commit verified work, then continue to the next authorized task.

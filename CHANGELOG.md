# Changelog

## 0.2.0 — Cloudflare distribution candidate

- Administrator Diagnostics with bounded sanitized traces, safe reports, configurable short-term retention and links to existing audit records.
- Migration Center: local legacy/encrypted package previews and selected-only new private draft imports, with per-file outcomes and retry receipts.
- Recognizable, editable sanitized backup filename labels with date/random suffix; encryption and legacy import remain compatible.
- Guided independent Cloudflare installation, schema/build identification and authenticated Help.
- Architecture/portability/support documentation only for future Local Only/Linux/add-ons. No new edition, sync, licensing, payment or monitoring service.

Release acceptance and exact live measurements are recorded in LOGBOOK.md. Do not interpret this candidate heading as a published distribution release. Existing Cloudflare bindings, account passwords, guest permissions and publication state are preserved.
